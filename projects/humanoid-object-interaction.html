Contact-planner-based humanoid object interaction

Master's thesis on object interaction with the Unitree G1, using a learned contact planner.

Overview

My master's thesis, in the Articulated Robotics Group at the Oxford Robotics Institute, is on contact-planner-based object interaction for the Unitree G1 humanoid. It combines human motion retargeting, whole-body motion tracking and learned contact planning, with the aim of deploying on the real robot.

Status: in progress. I'm currently reproducing OmniContact in simulation.
